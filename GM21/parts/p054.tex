Let us say that a graph $G$ is a $p$-chain if there exist $Y, Z \subseteq V(G)$ with $|Y| = |Z| \le p$, such that there is a unique set of $|\delm{X}\fix{Y}|$ mutually vertex-disjoint paths of $G$ between $Y$ and $Z$,\fixnote{fix:12-chain}{No set $X$ is defined, and the number of paths is $|Y| = |Z|$.} and every vertex of $G$ belongs to one of these paths.
