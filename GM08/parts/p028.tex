\sectionhead{16. \textsc{Boundary-linking} \textsc{In} \textsc{Tubes}}

Let $\Sigma$ be a cylinder, and let $r, s \ge 0$ be integers. A framing $(\Gamma, F_1, F_2)$ in $\Sigma$ is said to be \textit{$(r, s)$-boundary-linked} if there exist $\Gamma$-normal laminar hoops $F_1', F_2' \subseteq \Sigma(F_1, F_2)$ such that

\hspace*{12pt}(i) $F_2' \subseteq \Sigma(F_1, F_1')$, $F_1' \subseteq \Sigma(F_2, F_2')$

\hspace*{12pt}(ii) $(\Gamma \cap \Sigma(F_1', F_2'), F_1', F_2')$ has width $\ge r$ and length $\ge s$

\hspace*{12pt}(iii) for $i = 1, 2$ there are $|V(\Gamma) \cap F_i|$ mutually vertex-disjoint paths of $\Gamma$ between $F_i$ and $F_i'$.

Let $k, r, s \ge 0$ be integers, and let $\mathcal{B}(k, r, s)$ denote the class of all grafts of index $\le k$ which have framings in $\Sigma$ which are not $(r, s)$-boundary-linked. Let $\mathcal{B}(k)$ denote the class of all tubular grafts with index $\le k$. The main result of this section is the following.

\stmt
(16.1) \textit{If $\mathcal{B}(k - 1)$ is well-rooted then so is $\mathcal{B}(k, r, s)$, for any integers $k, r, s \ge 0$.}

[We interpret $\mathcal{B}(-1) = \emptyset$.]
