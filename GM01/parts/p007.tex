$u_0, v_0,..., u_r, v_r$ with $r\ge 0$, such that $u=u_0$, $v_r=v$, and for $1\le i\le r$, $v_{i-1}$,

Then $(V(G), <)$ is a strict partial ordering.}

We must check that if $u<v<w$, then $u<w$; and that $v\nless v$. First, if
$u<v<w$, let
\begin{align*}
u&=u_0, v_0,..., u_r, v_r=v,\\
v&=u_0', v_0',..., u_s', v_s'=w,
\end{align*}
be the corresponding sequences. Then the sequence
\begin{equation*}
u=u_0, v_0,..., u_r, v_0', u_1',..., u_s', v_s'=w
\end{equation*}
demonstrates that $u<w$. Second, if $v<v$, then there is a sequence
\begin{equation*}
v=u_0, v_0,..., u_r, v_r=v;
\end{equation*}
we have $r\ge 1$, since $u_0\ne v_0$, and so the sequence $u_1, v_1, u_2, v_2,..., u_{r-1}$,
$v_{r-1}, u_r, v_0$ contradicts the result of step 2. Hence $<$ is a strict partial
ordering.
