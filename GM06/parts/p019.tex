Let $h \colon [0, 1] \to \Sigma$ be defined by
\begin{equation*}
h(x) = \left( 2, \left( \frac{2i-x}{k} + 2\theta(\mathscr{L}) \right) \pi \right) \qquad (0 \le x \le 1).
\end{equation*}
Let $f \colon [0, 1] \to \Sigma$ be defined by
\begin{align*}
f(x) &= g(2x) && (0 \le x \le \frac{1}{2}) \\
&= h(2x - 1) && (\frac{1}{2} \le x \le 1).
\end{align*}
Then $f$ is a helix, $L(f) = 1$ and $\theta(f) = \theta(\mathscr{L}) - 1/k$. Hence $\phi(f) = \theta(\mathscr{L})$, as required. As a corollary we have the following justification for our algorithm.

\stmt
(5.6) \textit{If $(G', \mathscr{L}')$ is produced from $(G, \mathscr{L})$ by one of the reductions 1,..., 4, then $\theta(\mathscr{L}') + 1/k$ is feasible in $G'$ if and only if $\theta(\mathscr{L}) + 1/k$ is feasible in $G$.}

\textit{Proof.} ``Only if'' follows from (5.4). To prove ``if'', suppose that $\theta(\mathscr{L}') + 1/k$ is not feasible in $G'$. Then by (5.3) there is a helix $f'$ in $G'$ with $\phi(f') = \theta(\mathscr{L}')$, and by (5.5) there is a helix $f$ in $G$ with $\phi(f) \le \phi(f')$. But $\theta(\mathscr{L}') = \theta(\mathscr{L})$, and so
\begin{equation*}
\phi(f) \le \phi(f') = \theta(\mathscr{L}') = \theta(\mathscr{L}).
\end{equation*}
Hence by (5.2), $\theta(\mathscr{L}) + 1/k$ is not feasible in $G$. Let us state the algorithm.

\stmt
(5.7) \textit{Algorithm to decide if $\theta(\mathscr{L}) + 1/k$ is feasible.} We apply any of the reductions which can be applied, transforming to smaller equivalent problems by (5.6). If none of the reductions apply we determine feasibility by (5.1).

The algorithm can easily be adapted to provide us with a linkage $\mathscr{L}'$ satisfying $\theta(\mathscr{L}') = \theta(\mathscr{L}) + 1/k$ if one exists. Its running time is polynomially bounded, as may easily be checked. \fix{We check this. We apply reduction 4 only when none of reductions 1, 2, 3 applies. Each of

As further corollaries we have

\stmt
(5.8) \textit{If $\theta$ is feasible in $G$, the following are equivalent:} (i) \textit{there is a helix $f$ in $G$ with $\phi(f) = \theta$} (ii) \textit{$\theta + 1/k$ is not feasible} (iii) \textit{no $\theta' > \theta$ is feasible.}

\textit{Proof.} By (5.2), (i) $\Rightarrow$ (iii). Trivially (iii) $\Rightarrow$ (ii), and by (5.3), (ii) $\Rightarrow$ (i).
